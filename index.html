ONE PROMPT · FURNITURE 3D

Một prompt điều phối toàn bộ quy trình: phân tích ảnh → xác nhận hình học → đặc tả → tạo mesh → xem 3D → kiểm định → xuất OBJ / GLB / FBX khi nền tảng hỗ trợ.

01 · Nguồn tham chiếu

Chọn nhiều ảnh cùng lúc hoặc chọn thêm lần nữa. Gán hướng cho từng ảnh, có thể xóa ảnh không cần thiết.

Chưa có ảnh tham chiếu.

Kích thước xác nhận (mm, để trống nếu chưa biết)

Mỗi ô là một thông số độc lập. Không biết kích thước nào thì để trống ô đó.

02 · Prompt toàn quy trình

Đây là prompt hướng dẫn AI có công cụ tạo file 3D. Prompt không tự biến nền tảng chỉ hỗ trợ văn bản/ảnh thành công cụ tạo mesh.

Bộ não tạo prompt có 5 mục cố định, khóa TOP/BOTTOM/FRONT/BACK/LEFT/RIGHT, sàn Y=0 và hướng xuất. Cần gửi ảnh riêng tới nền tảng đã chọn.

03 · Trình xem 3D HOANGGIA

Mặt lưới là sàn ở cốt ±0.000 (Y = 0). Xoay đúng hướng rồi chọn “Hạ chân về cốt 0” để đáy mô hình chạm sàn.

Chọn tệp GLB, GLTF, OBJ hoặc STL để xem 3D
